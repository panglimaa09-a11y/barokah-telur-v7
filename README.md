# CatatanBarokah Telur

Aplikasi web/PWA sederhana untuk pencatatan keuangan usaha telur.

## Fitur

- Uang masuk dan uang keluar
- Dashboard pemasukan, pengeluaran, dan saldo bersih
- Riwayat transaksi
- Edit dan hapus transaksi
- Search dan filter transaksi
- Grafik cashflow 7 hari
- Pengeluaran per kategori
- Penyimpanan lokal dengan `localStorage`
- PWA dengan manifest dan service worker
- XSS-safe rendering untuk input pengguna

## Jalankan lokal

```bash
npx serve . -l 8080
```

Buka `http://localhost:8080`.
